This repository is the **support desk** for NovusTerm. It contains **no source
code** — NovusTerm is a proprietary, closed-source product. It exists so you have
one clear, public place to report a problem.

## Report a bug

**[→ Open a bug report](https://github.com/NovusTerm/novus-term-support/issues/new?template=bug_report.yml)**

The fastest path is from inside the app: **Help ▸ Report a Bug**. It opens this
same form with your app version and OS already filled in.

Before you file, please [search the existing
issues](https://github.com/NovusTerm/novus-term-support/issues?q=is%3Aissue) —
someone may have hit it already.

> **NovusTerm never transmits the contents of your terminal.** A bug report
> carries how the app is **configured** — version, operating system, shell,
> language, plan — and never what you are **doing**: no scrollback, no commands,
> no file paths. Whatever you paste into an issue, you paste yourself — and issues
> here are **public**, so never include API keys, tokens, passwords, or private
> paths.

## Security vulnerabilities

**Do not open a public issue.** See [SECURITY.md](SECURITY.md) for the private
reporting channel.

## Anything else

Email **support@novusterm.com** — questions, billing, licensing, or an idea you
think NovusTerm should have.

This is a one-person project. Replies are best-effort, usually within a few
business days. Security reports are handled first.
